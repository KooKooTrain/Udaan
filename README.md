
# Udaan - Airport Management System

Grade 12 CBSE Computer Science project developed using Python, featuring a graphical user interface (GUI) built with Tkinter and a MySQL database for data management.




## Setup

You need the following libraries for this project
```
  pip install tkinter
  pip install Pillow 
  pip install prettytable
```
After installing the required libraries, run `setup.sql` to create the Udaan table in MySQL Database. Prior to this, ensure that you have a valid MySQL account, as you will need your MySQL username and password to log in and execute the SQL script.

Then, run `udaan.py` and the app will will pop up. To log in as a passenger, refer to the setup.sql file for the passenger User ID and password. The login credentials are also provided below for testing purposes.
